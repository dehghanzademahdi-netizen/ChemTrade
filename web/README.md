# ChemLink Web

نسخه وب ChemLink با رویکرد RTL و فارسی طراحی شده است.

## وضعیت فعلی
- صفحه اصلی بازار تخصصی مواد شیمیایی
- جستجوی آگهی
- دسته‌بندی‌ها
- نمایش آگهی‌های نمونه
- ورود / ثبت آگهی به‌صورت UI اولیه
- طراحی واکنش‌گرا برای دسکتاپ و موبایل

## مرحله بعد
اتصال همین رابط به Firebase مشترک با Android، سپس پیاده‌سازی احراز هویت SMS، حساب کاربری، ثبت/ویرایش کامل آگهی و پنل مدیریت آنلاین.
